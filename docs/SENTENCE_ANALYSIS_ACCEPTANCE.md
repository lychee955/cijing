安全边界：网络仅由主进程访问；远程基础地址必须为 HTTPS，不含地址认证、查询参数或完整生成路径；重定向禁止跟随；主机变化清除旧密钥；已保存密钥不回填界面、不进入来源快照或日志。没有服务商或模型自动回退。

只因明确的结构化格式参数不支持错误，才允许同配置、同模型退到文本模式再生成一次；成功校验后按地址、模型、协议和所选模式记忆兼容模式。普通网络、超时、限流及格式错误均不自动生成重试。Retry-After 形成该配置的冷却期，鉴权失效仅暂停对应 AI 配置。

原文基础字段缺失、覆盖不完整或不匹配会拒绝结果；单个标注不可靠时保留文字讲解，移除错误高亮、提示降级，并禁止自动复用。取消、配置切换、编辑/删除在用配置及退出均取消任务；迟到响应不能写历史或覆盖新状态。测试连接不写分析历史。

## 请求响应诊断

按用户明确要求，原计划不记录完整原文的约束调整为记录 AI 请求/响应内容，并在终端和本地 `logs/ai.log` 输出脱敏日志。日志包含请求 ID、地址、协议/模型、请求体、状态、服务端错误详情、耗时、等待秒数和冷却拦截。鉴权、密钥、Cookie 遮盖；内容记录可用 `MOMO_AI_LOG_CONTENT=0` 关闭。单个体最多 64,000 字符，约 4 MB 文件轮转一份备份；日志失败不影响分析。

429 显示请求受限或模型繁忙；402 无 `Retry-After` 显示余额或额度不足，带等待时间的临时 402 按冷却处理。支持 HTTP 200 中的错误信封。真实原因以服务端响应为准，不从统一提示推断需要充值。依据：[OpenRouter 错误与等待时间](https://openrouter.ai/docs/api_reference/errors-and-debugging)。

按用户要求，句子分析和测试连接的接口失败在原提示下显示 HTTP 状态和脱敏后的服务端响应。详情跨适配器、服务与 IPC 保留，最大 8,000 字符，支持换行、长词折行和滚动；作为普通文本渲染，不执行响应内的 HTML。

应用日志确认一次 `deepseek-flash` 调用：请求 `max_tokens: 8192`，HTTP 200，`finish_reason: length`，输出用量和推理用量均为 8192，正文为空。旧默认上限使该次调用在推理阶段耗尽预算，不能视为完整分析。按用户最新要求，已完整删除输出长度配置字段、界面控件及两个协议的请求参数。读取旧配置自动剥离旧字段，重新保存清理旧字段，密钥保持可用；旧字段不能进入新来源快照、复用键或请求。截断提示保留服务端结束原因与输出/推理用量，并明确应用未发送上限。服务自己的默认值、输出/上下文上限仍适用。该次真实调用未形成质量验收结果。

接口与模板依据：[OpenRouter 接入](https://openrouter.ai/docs/quickstart)、[Qwen3.8 27B 模型 ID](https://openrouter.ai/qwen/qwen3.8-27b:free)、[Groq 兼容接口](https://console.groq.com/docs/openai)、[Gemini generateContent](https://ai.google.dev/api/generate-content)、[Gemini 结构化输出](https://ai.google.dev/gemini-api/docs/structured-output)、[Gemini 3.7 Flash 的 API ID](https://ai.google.dev/gemini-api/docs/models/gemini-3.7-flash)、[智谱标准基础地址示例](https://docs.bigmodel.cn/cn/best-practice/case/ai-search-engine)。已确认 Gemini 模板 ID 为 `gemini-3.7-flash`；账号权限与额度仍由实际连接验证，模板不承诺可用性或免费额度。
