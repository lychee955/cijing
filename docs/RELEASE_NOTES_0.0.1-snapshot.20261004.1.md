# 词境 v0.0.1-snapshot.20261004.1 · 快照测试版（发布说明草稿）

词境是一款桌面英语学习工具，将查词、句子解析与生词收录放在一起，帮助你理解英文，并把生词加入墨墨学习规划。

这是词境的快照开发版本，尚未发布。计划提供 Windows x64 安装版和便携版；发布时须标记为 Pre-release，不设为 Latest。词境为独立第三方工具，不属于墨墨官方产品。

## 本次亮点

- **查词与发音**：查询英文词条，查看中文释义、英美音标并播放发音。
- **生词收录**：连接个人墨墨账号，将词条加入学习规划，查看学习状态和本地操作历史。
- **AI 句子分析**：查看翻译、句子主干、成分、从句、语法和重点词汇，并可将词汇带入查词流程。
- **仅翻译模式**：关闭「详细分析」后直接获取译文，保留原文段落结构。
- **多套 AI 配置**：支持 OpenAI 兼容接口和 Gemini 原生接口，可保存、测试并切换服务与模型；未配置墨墨也可使用 AI 功能。
- **本地历史**：保存查词收录操作及分析、翻译记录；分析历史支持删除和重新分析。
- **桌面体验**：支持托盘、可配置全局快捷键，以及浅色、深色和跟随系统的主题。默认使用 `Ctrl + Shift + M` 唤出窗口。
- **版本检查**：通过 Logo 下方的版本入口查看更新信息，前往发布页面下载新版本。

## 下载与使用

| 文件 | 用途 |
| --- | --- |
| `cijing-0.0.1-snapshot.20261004.1-win-x64-setup.exe` | 安装版，按安装向导完成安装 |
| `cijing-0.0.1-snapshot.20261004.1-win-x64-portable.exe` | 便携版，下载后直接运行 |

请选择本页 Assets 中的一个 `.exe` 文件。`snapshot.yml` 和 `.blockmap` 为更新配套文件，无需手动打开；`Source code` 是源码包。

首次使用：

1. 使用墨墨查词与收录功能：在「设置」中保存个人 Token。获取入口为墨墨 App → 我的 → 更多设置 → 实验功能 → 开放 API；在手机端开启自动同步。
2. 使用 AI 分析与翻译：在「设置 → AI 服务」中新增配置，填写自己的 API Key 和模型，测试连接后设为当前配置。
3. 返回「查词」或「句子分析」开始使用。

## 使用须知

- 当前仅支持构建 Windows x64 发行包；实际安装、启动和核心功能须在发布前验证。
- 安装包尚未进行代码签名，Windows 可能显示安全提示。
- 本版本尚未启用应用内下载安装更新。应用内检查只查询正式版，不会发现其他快照；快照更新请手动访问 Releases 列表。没有正式版时，检查更新会提示无法确认发布信息。
- AI 功能需要自行配置服务，费用、额度和可用性由所选服务商决定。详细分析面向单句或短段落，最多 300 个英文单词、6,000 个字符。
- 本版本未与旧安装隔离，不适合并行安装；请先备份或使用独立测试账号。配置和历史保存在 `%APPDATA%/cijing/`；便携版也使用此目录。Token 和 API Key 在本机加密保存。
- AI 请求会发送至所配置的服务，本地诊断日志默认记录请求与响应内容，分享日志前请检查其中的原文和个人信息。
- 学习记录同步可能存在延迟；添加结果待确认时，请先确认状态，避免重复提交。
