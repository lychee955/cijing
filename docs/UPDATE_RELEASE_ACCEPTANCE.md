## 仍未完成，不能视为已验收

1. Windows 发行证书和正式签名构建。当前应用安装包未签名。
2. 隔离系统中的真实 NSIS 安装、portable 启动器环境、已安装旧版到新版的完整更新、失败恢复与凭证/历史保留。
3. 配置完证书并通过真实升级验收后启用 `windowsX64NsisValidated`。
4. 自动安装启用后的完整升级链路验收；当前快照仅规划手动下载安装。
5. macOS、其他架构和 GitHub Actions 为后续阶段，本次未启用。

当前版本已提供版本检查和手动下载路径；自动安装处于关闭状态。测试用 0.2.2 不应上传，构建阶段的其他 0.2.1 中间目录也不应混入最终产物。

此前 0.2.1 和 0.2.2 均为本地开发验证版本，不作为公开发行产物。每次快照必须使用对应新版本的构建目录及其 `release-manifest.json`，不得混用旧包。

具体发布步骤见 [RELEASING.md](RELEASING.md)，发布说明见 [快照发布说明草稿](RELEASE_NOTES_0.0.1-snapshot.20261004.1.md)。
