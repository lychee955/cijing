# 词境 v0.0.2-snapshot.20261005.1 · 配置与主题体验优化

本次快照优化设置页的配置刷新、跟随系统的主题切换和更新检查。提供 Windows x64 安装版和便携版，供提前体验与反馈问题；本版本标记为 Pre-release，不作为正式版推送。

## 本次更新

- **配置刷新**：设置页统一读取账号状态，保存或清除配置后重新获取最新结果，减少重复读取和旧状态覆盖。
- **主题切换**：选择「跟随系统」后，应用响应系统的浅色、深色变化；统一页面与 AI 配置弹窗的主题样式。
- **更新检查**：通过仓库的静态清单检查正式版本；尚无正式版时显示「暂无正式版本发布。」。快照仍需从 Releases 页面手动下载。
- **操作流程**：整理查词、收录确认和弹窗关闭流程中的重复处理，保留现有操作方式。

## 下载与使用

| 文件 | 用途 |
| --- | --- |
| `cijing-0.0.2-snapshot.20261005.1-win-x64-setup.exe` | Windows x64 安装版 |
| `cijing-0.0.2-snapshot.20261005.1-win-x64-portable.exe` | Windows x64 便携版，下载后直接运行 |

请选择本页 Assets 中对应的 `.exe` 文件。`snapshot.yml` 和 `.blockmap` 为更新配套文件，无需手动打开；`Source code` 是源码包。

## 升级说明

- 退出正在运行的词境，备份 `%APPDATA%/cijing/` 后，再手动安装本版或替换便携版 EXE。
- 快照与已有安装共用应用标识和用户数据目录，不适合并行安装；便携版也使用 `%APPDATA%/cijing/`。建议使用独立测试账号。
- 本次未更改数据库结构。完整的真实安装升级、数据保留和失败恢复验收尚未完成，不承诺降级兼容。

## 已知问题与限制

- 当前仅提供 Windows x64 发行包，EXE 尚未进行代码签名，Windows 可能显示安全提示。
- 应用内下载安装更新保持关闭。应用内检查只查询正式版，不会发现其他快照；快照更新请手动访问 Releases 列表。
- AI 功能需要自行配置服务，费用、额度和可用性由所选服务商决定。详细分析面向单句或短段落，最多 300 个英文单词、6,000 个字符。
- AI 请求会发送至所配置的服务，本地诊断日志默认记录请求与响应内容，分享日志前请检查其中的原文和个人信息。
- 学习记录同步可能存在延迟；添加结果待确认时，请先确认状态，避免重复提交。
- 词境为独立第三方工具，不属于墨墨官方产品。
